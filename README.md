# Bayesian Coresets for Density-Based Clustering via Predictive Matching

Code and saved results for the paper. The coreset is an affine transformation of a small uniform
subsample, chosen so that the predictive density-based partitions it produces match those of the
full data on a held-out reference set (Algorithm 1: `build_coreset_selected` in
`coreset/algorithm.py`).

## Installation

```bash
conda env create -f environment.yml
conda activate coresets
pytest tests            # 33 tests, about 30 s
```

All results were produced with Python 3.10 and the package versions pinned in
`environment.yml` (also listed in `requirements.txt`), on CPU.

## Repository layout

| Path | Contents |
|---|---|
| `coreset/` | the method: Pólya-urn predictive sampling (`polya_urn.py`), level-set clustering of a trajectory (`clustering.py`), soft level-set loss and its optimisation (`soft_levelset.py`), Algorithm 1 with the λ-path selection step (`algorithm.py`), VoI and the paired reference-set loss (`distances.py`), the QNC baseline for the curved simulation (`qnc.py`) |
| `inference/` | hyperprior on the base measure (`hyperpriors.py`), blocked Gibbs for a diagonal mixture (`gibbs_diag.py`), NumPyro mixtures and co-clustering summaries used by the curved simulation |
| `data/` | data generator for the curved simulation, loaders for Levine_13dim and Visium |
| `experiments/` | one script per study or analysis (table below) |
| `experiments/results/` | saved per-replicate results (JSON) read by the tables and figures |
| `experiments/figures/` | figure scripts; output goes to `figures/` |
| `figures/` | the figures of the paper and supplement, as generated from the saved results |
| `tests/` | unit tests |

## Data

* **Simulations** are generated by the scripts from fixed seeds.
* **Levine_13dim** (Weber & Robinson 2016) is exported from the Bioconductor package
  `HDCytoData`:
  ```bash
  Rscript data/export_cytof.R        # writes data/cytof/Levine_13dim.csv.gz
  ```
  The development/test split of the cells is fixed in `data/cytof.py`.
* **Visium** (10x Genomics H&E mouse brain) is downloaded through `squidpy` and preprocessed by
  `data/visium.py`. The preprocessed arrays used for the paper are included in
  `experiments/results/visium/visium_cache.npz`.

## Reproducing the tables and figures from the saved results

These commands read only `experiments/results/` and take seconds:

```bash
python experiments/figures/make_figures.py          # all figures except the baselines figure
python experiments/figures/fig_baselines.py         # baselines figure
python experiments/exp_sim_valleys.py --summarise   # Table 1
python experiments/exp_levine13.py --split test --summarise
python experiments/levine13_report.py               # Table 2
python experiments/exp_qnc_baseline.py --summarise
python experiments/exp_claici_baseline.py --summarise
python experiments/exp_supp_replication.py --summarise
python experiments/exp_kcl_sensitivity.py --summarise
python experiments/exp_alpha_sensitivity.py --summarise
python experiments/time_coreset.py --summarise
```

The cluster-map figures use representative replicates cached in
`experiments/results/cluster_maps/` by `experiments/figures/make_cluster_maps.py`, which needs
the raw data.

## Rerunning the studies

Each replicate is seeded from a master seed and its index (`numpy.random.SeedSequence`), so
replicates can be run in any order or in parallel. Scripts skip replicates whose result file
already exists. Times are for one replicate on one core.

| Paper | Script | Results | Time per replicate |
|---|---|---|---|
| Section 4.2, Table 1 (valley simulation) | `exp_sim_valleys.py --reps 0-19 --n_jobs 16` | `sim_valleys/` | ≈ 2.5 min |
| Section 4.3, Table 2 (Levine_13dim) | `exp_levine13.py --split test --ns 50,100,150,250,400,1000 --reps 0-29 --n_jobs 8` | `levine13_test/` | ≈ 2 min |
| Supplement: curved clusters, d = 20 | `exp_sim_curved.py --runs 0-99` (n = 50); `--n 25`, `--n 100`, `--n 200` with `--runs 0-19` | `sim_curved_n*/` | ≈ 5 min |
| Supplement: Visium | `visium_choose_d.py`, then `exp_visium.py --reps 0-19` | `visium/` | ≈ 1 min |
| Supplement: QNC baseline | `exp_qnc_baseline.py --study valley` and `--study levine` | `qnc_baseline/` | |
| Supplement: W₂ affine-map baseline | `exp_claici_baseline.py --study valley` and `--study levine` | `claici_baseline/` | |
| Supplement: replication loss, equivalent uniform size | `exp_supp_replication.py --study valley` and `--study levine` | `supp_replication/` | |
| Supplement: sensitivity to K_cl | `exp_kcl_sensitivity.py` | `kcl_sensitivity/` | |
| Supplement: sensitivity to α | `exp_alpha_sensitivity.py` | `alpha_sensitivity/` | |
| Supplement: implementation details (bandwidth, cost of one clustering) | `diag_bandwidth_cost.py` | `diag_bandwidth_cost/` | |
| Supplement: convergence of the uniform subsample | `exp_uniform_convergence.py` | `uniform_convergence.json` | |
| Construction times | `time_coreset.py --study valley\|curved\|levine\|visium --reps 0-4` (one study at a time, idle machine) | `timings/` | |

All scripts are run from the repository root, e.g. `python experiments/exp_sim_valleys.py ...`.
The baseline, replication and sensitivity analyses replay the stored replicates of the main
studies from their seeds (same data, reference set, support and evaluation draws), so they need
the corresponding results in `experiments/results/`.
